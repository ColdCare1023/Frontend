# ColdCare

Web B2B para supervisión de cadena de frío farmacéutica, dentro del alcance de una tesis. Equipos de farmacia consultan temperatura interna, temperatura ambiental, humedad, puerta, conectividad, historial, alertas, acciones, integridad y reportes. Administración mantiene usuarios y dispositivos; permisos existentes por rol se conservan.

Fuente funcional: Anexo5PB_Soto_Diego_Gamio_Brenda.xlsm, 56 HU y 288 SP. Alcance de esta intervención: presentación del frontend existente. No implementar backend, IoT, persistencia, cloud, funciones ni reglas nuevas.

Rango de referencia fijo 2–8 °C. RF clasifica normal/riesgo preventivo; excursión térmica corresponde a regla independiente. Fallo de sensor y ausencia de datos no equivalen cero ni excursión. Datos demo se identifican como simulados; UI no acredita validación de campo, evaluación IA, seguridad operativa ni integridad real.

Usuarios necesitan lectura rápida y controles consistentes durante operación. Prioridad: claridad en laptop de presentación, tablas utilizables, acciones accesibles, estados legibles y navegación adaptable. Identidad oficial: Inter, azul #0B5CFF, cian #00D1FF, rosa #FF7AA2, navy #0F172A y fondo #F4F7FB. Stack actual se preserva.
